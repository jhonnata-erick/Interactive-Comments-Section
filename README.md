Interactive Comments Section (Legacy Rescue)

A complete refactor of my previous Interactive Comments Section project.

The goal of this repository is not to rebuild the application from scratch, but to treat my original implementation as a legacy codebase and refactor it using modern frontend engineering practices.

Objectives

During this refactor I intend to focus on:

Migrating the project to TypeScript
Improving the application architecture
Better separation of concerns
Building reusable and scalable components
Improving state management
Adding automated tests
Enhancing accessibility
Reducing technical debt
Following a professional Git workflow

TypeScript

Why This Project?

Most portfolio projects focus on building new features.

This project focuses on something equally important in professional environments: understanding, maintaining and improving an existing codebase while preserving its original functionality.
